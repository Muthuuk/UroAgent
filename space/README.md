# UroAgent

Multi-agent decision support for overactive bladder, bladder pain syndrome and urinary tract infection:
triage, safety rules, ensemble classification with SHAP, guideline retrieval with citations, symptom scoring,
conversation memory and seven MCP-style clinical tools.

**Research demonstrator only: synthetic data, not a medical device. Every output is advisory and needs clinician review.**

Source code, Colab notebook and documentation: https://github.com/Muthuuk/UroAgent
